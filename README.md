# خَمِّن الرسمة 🎨

لعبة عربية بسيطة للأطفال: تختار المعلمة أو الطالبة بطاقة سرية من ثلاث بطاقات، ثم ترسمها، ويحاول الأطفال تخمين الرسمة.

## تشغيل اللعبة

افتحوا ملف `index.html` في المتصفح، أو استخدموا رابط GitHub Pages بعد تفعيله.

## نشرها كرابط عام

1. افتحي إعدادات المستودع (**Settings**).
2. اختاري **Pages** من القائمة الجانبية.
3. تحت **Build and deployment** اختاري **Deploy from a branch**.
4. اختاري الفرع `main` والمجلد `/ (root)` ثم اضغطي **Save**.
5. بعد دقائق سيظهر رابط اللعبة في صفحة Pages، ويكون عادةً:
   `https://areejshaml.github.io/guess-the-drawing-ar/`

اللعبة الحالية تعمل على جهاز واحد، وهي مناسبة للصف أو العائلة. اللعب الجماعي الحقيقي من أجهزة مختلفة يحتاج خادمًا وقاعدة بيانات، ويمكن إضافتهما في مرحلة لاحقة.
